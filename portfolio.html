Flagship Case Study — Group Project (3-person team)

iSkolar ng Bayan — Scholarship Management & Academic Monitoring System

Schools managing scholarships relied on manual, paper-based tracking of applications, GPA eligibility, and slot counts — slow to update, and scholars had no way to check their own status.

Problem

Scholarship applications, scholar records, grades, and announcements were tracked manually, with no shared system for admins or scholars to monitor status in real time.

Architecture & Stack

PHP + MySQL (managed via phpMyAdmin), deployed on Hostinger behind Cloudflare. Role-based Admin/Scholar portal — a straightforward relational fit for linked users, scholarships, applications, and grades on affordable shared hosting.

My Contribution

  • Co-built the system as part of a 3-person dev team
  • Authored the full governance documentation — SLA, OLA, KPI scorecard, and SOPs (below)

Measurable Results

Application lifecycle verified end-to-end across all four states (Pending → Under Review → Approved/Rejected), each confirmed via in-app toasts. Governance plan sets 99.5% uptime and 95% user-satisfaction targets, with SOPs covering backups, password resets, and slot management.

Documentation — Service Governance Portfolio

SLA / OLA / KPI scorecard / hyper-care plan, plus step-by-step SOPs for:

  • Password reset (Admin → User List → Edit)
  • Weekly database backup via phpMyAdmin export
  • Adding a scholar & processing an application (auto GPA check)
  • Scholarship slot management (auto-adjusts on approval/deletion)
